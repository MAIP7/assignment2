# Gemini AI Assistant Web App

A clean and simple AI chat application integrated with Google Gemini Free API.

## Features
- Direct Gemini 2.5 Flash API integration
- Local storage based API key preservation (Safe for GitHub)
- Conversation history retention
- Responsive UI built with Tailwind CSS & Marked.js

## How to use
1. Get a free API key from [Google AI Studio](https://aistudio.google.com/).
2. Paste the key in the top input box and click "Save Key".
3. Start chatting!
